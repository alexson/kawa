# Kawa

> **Work in progress** — this project is under active development and is not ready for general use.

Kawa is a macOS input source switcher with user-defined shortcuts. This repository is a work in progress; features, setup instructions, and behavior may change.

## Status

Development is ongoing. Installation and usage instructions will be added when the project is ready for users.

## Development

The app is built with Xcode. Open the project in Xcode to work on it.
